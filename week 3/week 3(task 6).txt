Sometimes it's better to use dynamic size arrays. Java's Arraylist can provide you this feature. Try to solve this problem using Arraylist.

You are given  lines. In each line there are zero or more integers. You need to answer a few queries where you need to tell the number located in  position of  line.

Take your input from System.in.

Input Format
The first line has an integer . In each of the next  lines there will be an integer  denoting number of integers on that line and then there will be  space-separated integers. In the next line there will be an integer  denoting number of queries. Each query will consist of two integers  and .

Constraints

Each number will fit in signed integer.
Total number of integers in  lines will not cross .

Output Format
In each line, output the number located in  position of  line. If there is no such position, just print "ERROR!"

import java.io.*;
import java.util.*;

public class Solution {

    public static void main(String[] academind) {
        Scanner scanner = new Scanner(System.in);
        
        // Read the number of rows
        int n = scanner.nextInt();
        
        // Create a dynamic 2D structure (List of Lists)
        List<List<Integer>> rows = new ArrayList<>();
        
        for (int i = 0; i < n; i++) {
            int d = scanner.nextInt();
            List<Integer> currentRow = new ArrayList<>();
            
            for (int j = 0; j < d; j++) {
                currentRow.add(scanner.nextInt());
            }
            rows.add(currentRow);
        }
        
        // Read the number of queries
        int q = scanner.nextInt();
        
        for (int i = 0; i < q; i++) {
            // Convert 1-based index from input to 0-based index for ArrayList
            int x = scanner.nextInt() - 1; 
            int y = scanner.nextInt() - 1;
            
            // Validate if row x exists and if column y exists within that row
            if (x >= 0 && x < rows.size() && y >= 0 && y < rows.get(x).size()) {
                System.out.println(rows.get(x).get(y));
            } else {
                System.out.println("ERROR!");
            }
        }
        
        scanner.close();
    }
}
