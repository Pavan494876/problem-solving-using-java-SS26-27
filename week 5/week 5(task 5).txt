Implement the myAtoi(string s) function, which converts a string to a 32-bit signed integer.

The algorithm for myAtoi(string s) is as follows:

Whitespace: Ignore any leading whitespace (" ").
Signedness: Determine the sign by checking if the next character is '-' or '+', assuming positivity if neither present.
Conversion: Read the integer by skipping leading zeros until a non-digit character is encountered or the end of the string is reached. If no digits were read, then the result is 0.
Rounding: If the integer is out of the 32-bit signed integer range [-231, 231 - 1], then round the integer to remain in the range. Specifically, integers less than -231 should be rounded to -231, and integers greater than 231 - 1 should be rounded to 231 - 1.
Return the integer as the final result.

program:
class Solution {
    public int myAtoi(String s) {
        // Handle empty or null string edge cases
        if (s == null || s.isEmpty()) {
            return 0;
        }

        int index = 0;
        int n = s.length();
        int sign = 1;
        int total = 0;

        // 1. Skip leading whitespaces
        while (index < n && s.charAt(index) == ' ') {
            index++;
        }

        // Check if string became empty after removing whitespaces
        if (index == n) {
            return 0;
        }

        // 2. Check for optional sign character
        char firstChar = s.charAt(index);
        if (firstChar == '+' || firstChar == '-') {
            sign = (firstChar == '-') ? -1 : 1;
            index++;
        }

        // 3. Convert digits and guard against overflow
        while (index < n) {
            char currentChar = s.charAt(index);
            
            // Break early at the first non-digit character
            if (currentChar < '0' || currentChar > '9') {
                break;
            }

            int digit = currentChar - '0';

            // 4. Over/Underflow Validation (32-bit Limit Check)
            // Integer.MAX_VALUE is 2147483647. The critical threshold is 214748364.
            if (total > Integer.MAX_VALUE / 10 || 
               (total == Integer.MAX_VALUE / 10 && digit > Integer.MAX_VALUE % 10)) {
                return (sign == 1) ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }

            // Append digit to our accumulated total
            total = total * 10 + digit;
            index++;
        }

        return total * sign;
    }
}
