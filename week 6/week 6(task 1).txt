For two strings A and B, we define the similarity of the strings to be the length of the longest prefix common to both strings. For example, the similarity of strings "abc" and "abd" is 2, while the similarity of strings "aaa" and "aaab" is 3.

Calculate the sum of similarities of a string S with each of it's suffixes.

Input Format

The first line contains the number of test cases t.
Each of the next t lines contains a string to process, .

Constraints

 is composed of characters in the range ascii[a-z]
Output Format

Output t lines, each containing the answer for the corresponding test case.

Sample Input

2
ababaa  
aa
Sample Output

11  
3
program:
import java.io.*;
import java.util.*;
import java.util.stream.*;

public class Solution {

    public static long solveStringSimilarity(String s) {
        int n = s.length();
        int[] z = new int[n];
        
        int l = 0, r = 0;
        for (int i = 1; i < n; i++) {
            if (i <= r) {
                z[i] = Math.min(r - i + 1, z[i - l]);
            }
            while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) {
                z[i]++;
            }
            if (i + z[i] - 1 > r) {
                l = i;
                r = i + z[i] - 1;
            }
        }
        
        // Java 8 Stream Pipeline: Sum Z-array values and add the full length 'n'
        return n + Arrays.stream(z).asLongStream().sum();
    }

    public static void main(String[] args) {
        // Java 8 Automatic resource management (Try-with-resources)
        try (BufferedReader br = new BufferedReader(new InputStreamReader(System.in))) {
            String line = br.readLine();
            if (line == null) return;
            
            int t = Integer.parseInt(line.trim());
            StringBuilder sb = new StringBuilder();
            
            while (t-- > 0) {
                String s = br.readLine().trim();
                sb.append(solveStringSimilarity(s)).append("\n");
            }
            System.out.print(sb);
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
