Given an integer array nums, find the subarray with the largest sum, and return its sum.

 

Example 1:

Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: The subarray [4,-1,2,1] has the largest sum 6.
Example 2:

Input: nums = [1]
Output: 1
Explanation: The subarray [1] has the largest sum 1.
Example 3:

Input: nums = [5,4,-1,7,8]
Output: 23
Explanation: The subarray [5,4,-1,7,8] has the largest sum 23.
 

Constraints:

1 <= nums.length <= 105
-104 <= nums[i] <= 104
program:
import java.util.Arrays;

class Solution {
    public int maxSubArray(int[] nums) {
        // Use collect to safely mutate a state array tracking [currentMax, maxSoFar]
        return Arrays.stream(nums, 1, nums.length)
                .collect(
                    () -> new int[]{nums[0], nums[0]}, // Supplier: [currentMax, maxSoFar]
                    (state, element) -> {              // Accumulator
                        state[0] = Math.max(element, state[0] + element);
                        state[1] = Math.max(state[1], state[0]);
                    },
                    (state1, state2) -> {              // Combiner (for parallel streams)
                        throw new UnsupportedOperationException("Parallel execution not supported");
                    }
                )[1]; // Return maxSoFar
    }
}
